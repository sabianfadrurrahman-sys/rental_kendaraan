# NTI Vehicle Rental

Modul kustom Odoo untuk manajemen penyewaan kendaraan.

## Deskripsi
Modul ini digunakan untuk mengelola armada kendaraan, transaksi pemesanan rental, serta pelaporan terkait penyewaan kendaraan.

## Fitur Utama
- Manajemen data kendaraan
- Pencatatan reservasi / rental
- Akses kontrol dan pelaporan

## Persyaratan
- Odoo Server (v14/v15/v16/v17 sesuai versi yang digunakan)
- Python 3.x
